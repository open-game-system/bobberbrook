# Art style

**Target (owner, 2026-10-08): Ashenvale** — a twilight night-elf forest: violet/indigo sky and fog, glowing
moonwell-teal water, colossal ancient trees with purple and teal canopies, mist, wisps, fireflies, glowing
flowers, curved purple-roofed elven cottages. References: concept/ashenvale/ref-day.jpg, ref-night.jpg.

Hand-painted fantasy-MMO diorama: chunky low-poly
shapes with soft bevels, oversized rounded trees, saturated warm-cool colour, painted gradients,
minimal specular, warm key light and cool fill. Not papercraft, not ink outlines, not felt.

- Palette: deep lake teal #0f3b3f, lake #1f7a86, shallows #4fc0c4, wood #7a4a22 / #b07a42, leaf #5fbf4a,
  sun #ffd25a, coral #ff7a4a. Seat colours: green #5fbf4a, yellow #f2c230, blue #3a8fe8, pink #f27aa8.
- Type (grown-up phone, TV HUD): Baloo 2.
- Fish: painted sprites (`public/art/fish/*.webp`, Codex sheets sliced by `scripts/slice-fish.py`).
- Prompt prefix (concept/prefix.txt and the kit prompts in this repo's history): "Stylized 3D game
  screenshot in the hand-painted fantasy MMO tradition: chunky low-poly geometry with soft bevels,
  oversized rounded trees and rocks, hand-painted diffuse textures with visible brush strokes…"
- Never: text in the world (except name tags), faces on objects, emoji, anything scary.
